# Prathamesh Mali — Portfolio

Static Next.js portfolio, built as a changelog/release-log of your work.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build static export

```bash
npm run build
```

Static files are output to `out/`. Deploy that folder anywhere
(Vercel, Netlify, GitHub Pages, or any static host).

## Stack

Next.js 15 (App Router, static export) · TypeScript · Tailwind CSS
Fonts: Space Grotesk (display) · IBM Plex Sans (body) · IBM Plex Mono (labels)

Resume PDF lives at `public/resume.pdf` and is linked from the nav.
